# Klasivo — Future Ideas

> **Status:** These ideas are NOT part of the locked roadmap (v1.0).  
> **Rule:** Only add to roadmap if a paying school requires it, or it's needed for security/compliance/scaling.  
> **Re-evaluation:** When Klasivo reaches 50+ schools.

---

## Growth Stage (50–100 schools)

### Teacher Performance & Development
- Attendance tracking, student engagement, assignment turnaround metrics
- Professional development modules, certifications, internal evaluations
- Teacher quality scoring and comparison

### School Benchmarking
- Anonymized cross-school comparison
- "Your attendance is in top 20%" insights
- Performance percentiles by subject, grade level, region
- Requires scale (50+ schools) for statistical significance

### Integration Hub
- Google Workspace (Calendar, Drive, Classroom sync)
- Microsoft 365 (Teams, OneDrive, Outlook)
- Zoom integration (alternative to LiveKit)
- Moodle import
- Accounting software (QuickBooks, Xero)
- LTI compliance (connect to any LTI tool)
- Government reporting APIs

### Competency-Based Education (Full)
- Competency definitions spanning multiple outcomes
- Progress maps with prerequisite relationships
- Personalized learning paths
- Portfolio-based assessment

---

## Scale Stage (500+ schools)

### School Accreditation Toolkit
- Evidence collection for accreditation standards
- Audit report generation
- Documentation for national and international accreditation bodies
- Premium feature for enterprise schools

### Student Career Pathway System
- Skills tracking, interest profiling, performance analysis
- University path recommendations
- Career path recommendations
- Course suggestions based on strengths

### Alumni Network
- Alumni directory and profiles
- Mentorship matching
- Event management
- Donation platform
- Network effect moat

### Finance & School Operations
- Tuition tracking and invoicing
- Payment processing (beyond SaaS billing)
- Scholarship management
- Discount structures
- Competes with full school ERP systems

---

## Platform Stage (1000+ schools)

### Digital Academic Identity
- Permanent academic record for every student
- Portable across schools (Grade 1 → Grade 12, School A → School B)
- University application portfolio
- Employment portfolio
- Scholarship applications
- Extremely valuable long-term moat

### School Knowledge Graph
- Relationship-aware data model (Student ↔ Teacher ↔ Subject ↔ Assignment ↔ Exam ↔ Outcome ↔ Parent)
- Enables: better analytics, AI recommendations, risk detection, personalized learning
- Long-term AI advantage over competitors

### Ecosystem Developer Platform
- Public REST API with OAuth 2.0
- Webhook system for real-time events
- SDKs (JavaScript, Python, Dart)
- Third-party app marketplace
- Developer portal with sandbox
- How products become platforms

---

## Mobile Growth Layer

- Referral system (teacher invites teacher, parent invites parent)
- Deep links (share assignment, share exam result)
- Invite parents from within the app
- Share achievements on social media
- Organic acquisition amplification

## Evaluation Criteria

For each future idea, score 1-10 on:

| Criteria | Weight | Description |
|----------|--------|-------------|
| Revenue Impact | 30% | Would schools pay specifically for this? |
| Adoption Impact | 25% | Would this help acquire new schools? |
| Retention Impact | 25% | Would this prevent schools from leaving? |
| Technical Complexity | 20% | How expensive is this to build? (inverse — lower complexity = higher score) |

**Threshold:** Only ideas scoring > 7.0 average move from this file to the roadmap.
